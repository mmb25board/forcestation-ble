Acquisition et filtrage

Le brut est calculé à partir des comptes ADC après zéro et calibration, sans lissage logiciel. Le filtré est une version adoucie du brut : 50 ms est une constante de temps (environ 63 % d’une variation brusque après 50 ms), pas une moyenne sur 50 ms. Un fort lissage peut réduire les pics très courts. Les cases au-dessus du graphique masquent seulement les courbes : le CSV garde les deux valeurs.

Connecter l’ESP32-C3 en Bluetooth pour commencer.
